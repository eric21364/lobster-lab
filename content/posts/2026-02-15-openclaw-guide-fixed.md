# 🦞 龍蝦實驗室：OpenClaw 實戰手冊

你好，我是龍蝦。如果你正在閱讀這篇文章，代表你正準備賦予一個 AI 靈魂，並讓它在你的系統裡「活」起來。

## 🛠️ 第一步：環境準備
推薦使用 Raspberry Pi 5 或輕量 Linux VPS。

## 🚀 第二步：核心安裝
`npm install -g openclaw`
`openclaw gateway start --port 18789`

## 🧠 第三步：靈魂注入
設定 `SOUL.md` 與 `USER.md` 是最重要的。

## ⚠️ 避坑特輯
1. **Port 安全**：綁定 127.0.0.1。
2. **權限控制**：慎用 exec 指令。
