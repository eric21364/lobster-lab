一、 環境準備：代理人的「溫床」

代理人需要一個隨時待命的環境。如果你關掉電腦它就消失了，那不叫代理人，那叫網頁插件。

  • 硬體選擇：
    • Raspberry Pi 5 (8GB)：絕佳的實體載體，省電且安靜。
    • 雲端 VPS：推薦 Ubuntu 22.04 LTS 或更高版本，記憶體至少 4GB。
  • 必備軟體： 
    # 確保 Node.js 環境在 v20 以上
nvm install 22 && nvm use 22
node -v  # 應顯示 v22.x.x

# 確保 Git 已經安裝
sudo apt install git -y

二、 核心啟動：OpenClaw 的誕生

OpenClaw 透過 CLI 管理一切。請在你的終端機執行以下神聖的指令：

# 1. 全域安裝 CLI 工具
npm install -g openclaw

# 2. 初始化你的工作目錄
mkdir my-lobster-base && cd my-lobster-base
openclaw init

# 3. 啟動 Gateway (指揮中樞)
openclaw gateway start --port 18789
⚠️ 避坑重點 #1：Port 安全防禦
啟動後，執行 ss -tunlp | grep 18789。請務必確認它綁定在 127.0.0.1。如果你設定成 0.0.0.0，全世界的人都可以透過 API 控制你的伺服器，這非常危險！

三、 通訊管道：Telegram 深度對接與配對

這是新手最容易卡住的地方。要讓代理人能跟你聊天，需要完成一套「配對」流程：

  1. 獲取 Token：找 @BotFather 建立機器人，拿到 API Token。
  2. 修改設定：編輯 openclaw.json，將 Token 填入 channels.telegram.botToken。
  3. 重啟服務：openclaw gateway restart。
  4. 關鍵配對 (Pairing Handshake)：
    • 在 Telegram 打開你的機器人，傳送 /start。
    • 機器人會回傳一組 **6 位數配對碼** (例如: 123456)。
    • 立刻回到終端機，執行： 
      openclaw pairing approve telegram 123456
    • 顯示 Pairing approved! 後，代理人才正式屬於你。

四、 賦予靈魂：Agent 代理人的設定

在 OpenClaw 裡，Agent 是你的代理人實體。預設名為 main。

1. 身份定義 (Identity)

在工作區建立以下核心檔案：

  • SOUL.md：決定代理人的靈魂。範例：「你是龍蝦，語氣直接且正能量，喜歡用 🦞 符號。」
  • USER.md：你是誰？代理人該如何稱呼你？
  • AGENTS.md：工作規範與限制（憲法）。

2. Agent 管理指令

# 查看當前運行中的 Agent 狀態
openclaw status --all

# 查看目前的對話 Session
openclaw sessions list --agent main

五、 持續進化：記憶系統維護

代理人的記憶分為 **Session 記憶** (當前聊天) 與 **長期記憶** (跨對話記憶)。

如何手動建立長期記憶？
  1. 建立 memory/ 資料夾。
  2. 每天由代理人自動（或你手動）產出 memory/2026-XX-XX.md。
  3. 建立一個總結性的 MEMORY.md 放在根目錄。
  4. 進階：在 SOUL.md 指示代理人：「每次對話完畢後，將學到的新事物寫入長期記憶檔案。」

六、 高階：VPS 遠端管理 (SSH 隧道)

如果你在遠端 VPS 運作，想在自家電腦開啟 Dashboard 管理介面：

# 在你的本地電腦 (不是伺服器) 執行
ssh -L 18789:127.0.0.1:18789 user@your-vps-ip

然後在瀏覽器打開 http://127.0.0.1:18789，你就能看到帥氣的管理畫面了。

七、 避坑特輯總結 (FAQ)

  • Q: 為什麼代理人說它沒權限刪除檔案？
    A: 檢查 openclaw.json 裡的 tools.allow 列表，是否有開啟 exec 功能。
  • Q: 如何備份？
    A: 最穩定的方式是將 /workspace 目錄直接掛載到 pCloud 或定時執行 git push。
  • Q: 如何安裝新技能？
    A: 使用 clawhub install [skill-name]，但切記安裝後要手動檢查代碼安全性。
