建立 OpenClaw AI 代理人指南

項目說明 / Description

本指南詳細介紹如何從零開始部署 OpenClaw 系統，並完成核心 Agent 的靈魂配置與通訊綁定。

環境部署 / Environment Setup

🛠️ STEP 1: 下載與安裝

推薦使用官方一鍵腳本安裝 Node.js 環境與 OpenClaw 核心：

curl -fsSL https://openclaw.ai/install.sh | bash

初始化與啟動 / Init & Start

mkdir my-agent && cd my-agent
openclaw init
openclaw gateway start --port 18789

通訊綁定 / Telegram Pairing

請遵循以下配對「握手」流程來啟用 Telegram 頻道：

  1. 在 openclaw.json 填入 Bot Token。
  2. 執行 openclaw gateway restart。
  3. 在 Telegram 傳送 /start 給 Bot 取得 6 位數配對碼。
  4. 在終端機執行：openclaw pairing approve telegram [配對碼]

賦予靈魂 / Soul Configuration

在工作區根目錄設定代理人的三大支柱：

  • SOUL.md：定義性格、風格、禁忌（代理人的心）。
  • USER.md：紀錄使用者的偏好與身份資訊。
  • AGENTS.md：憲法。規範執行權限與限制行為。

記憶與維修 / Memory & Maintenance

建立 memory/ 資料夾以儲存每日紀錄。若系統異常，請使用終極診斷工具：

openclaw doctor
⚠️ 重要提醒: 任何對 openclaw.json 的修改，都必須執行 openclaw gateway restart 才能生效。
