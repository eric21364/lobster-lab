建立 OpenClaw AI 代理人指南

本指南介紹如何從零開始建立 OpenClaw 系統，包含環境部署、通訊綁定及後續維護動作。

一、 環境部署

建議環境：Ubuntu VPS 或 Raspberry Pi 5，Node.js v20+。

curl -fsSL https://openclaw.ai/install.sh | bash

二、 初始化與啟動

mkdir my-agent && cd my-agent
openclaw init
openclaw gateway start --port 18789

三、 Telegram 綁定流程

  1. 在 openclaw.json 填入 Telegram Bot Token。
  2. 執行 openclaw gateway restart。
  3. 在 Telegram 對 Bot 傳送 /start 取得 6 位數配對碼。
  4. 執行：openclaw pairing approve telegram [配對碼]

四、 代理人（Agent）設定

在工作區根目錄設定以下檔案：

  • SOUL.md：定義代理人的個性與語氣。
  • USER.md：紀錄使用者的偏好。
  • AGENTS.md：規範代理人的行為權限。

五、 記憶維護

建立 memory/ 資料夾，讓代理人產出每日紀錄（YYYY-MM-DD.md），並定期更新根目錄的 MEMORY.md。這能確保代理人具備長期記憶能力。

六、 修改設定與更新

重要：修改 openclaw.json 後，必須執行 openclaw gateway restart 才能生效。

更新系統指令：

npm install -g openclaw
openclaw gateway restart

七、 診斷工具

若遇到功能異常，可執行診斷：

openclaw doctor

八、 進階遠端管理

使用 SSH 隧道安全連入管理介面：

ssh -L 18789:127.0.0.1:18789 user@your-vps-ip
