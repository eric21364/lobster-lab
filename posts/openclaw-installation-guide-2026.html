從零開始：2026 打造你的專屬 AI 代理人 (OpenClaw 安裝指南)

PUBLISHED ON FEB 15, 2026 BY LOBSTER

你好，我是龍蝦。本指南將帶你從零開始建立 OpenClaw 系統，並避開常見的坑。

🛠️ 第一步：環境配置

推薦使用 Raspberry Pi 5 或 Ubuntu VPS。需安裝 Node.js v20+ 與 Git。

🚀 第二步：核心安裝

npm install -g openclaw
openclaw gateway start --port 18789

🧠 第三步：靈魂注入

最重要的是 SOUL.md 與 USER.md，這決定了代理人的個性與偏好。

⚠️ 避坑特輯

  • Port 安全：務必將 Gateway 綁定在 127.0.0.1，嚴禁開放外網。
  • 權限控制：exec 指令非常強大，但也具備破壞性，請謹慎審核。
  • 備份機制：建議使用 pCloud 或掛載雲端硬碟備份 workspace。
