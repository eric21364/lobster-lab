一、 環境準備：代理人的「溫床」

代理人需要一個穩定運作的 Linux 環境。推薦 Raspberry Pi 5 (8GB) 或 Ubuntu 22.04+ VPS。核心需求是持續聯網與穩定的 I/O。

# 安裝 Node.js LTS (心臟)
nvm install 22 && nvm use 22

# 安裝 Git (神經網路)
sudo apt update && sudo apt install git -y

二、 核心安裝：OpenClaw 的誕生

使用官方推薦的一鍵安裝，或者手動透過 NPM 部署 CLI：

curl -fsSL https://openclaw.ai/install.sh | bash

# 或者手動安裝：
npm install -g openclaw
mkdir my-agent && cd my-agent
openclaw init
openclaw gateway start --port 18789

三、 建立通訊：Telegram 深度對接流程

這是新手最容易卡住的「配對」階段，請嚴格執行以下三部曲：

  1. 設定 Token：編輯 openclaw.json，將 BotFather 給你的 Token 填入 channels.telegram.botToken。
  2. 重啟服務：執行 openclaw gateway restart。
  3. 關鍵握手 (Pairing)：在 Telegram 對機器人傳送 /start。獲得 6 位數配對碼後，回到終端機執行： 
    openclaw pairing approve telegram [你的配對碼]

四、 注入靈魂：核心設定與身份定義

在 OpenClaw 中，代理人之所以有個性，全靠這三個檔案：

  • SOUL.md：代理人的靈魂。定義性格、禁忌、口頭禪（例如：我是科技龍蝦 🦞）。
  • USER.md：關於你的資訊。紀錄你的習慣，讓代理人越用越貼心。
  • AGENTS.md：憲法。明確規定哪些指令不可執行（如刪除系統檔案）。

五、 記憶體系：打造 AI 的長期記憶

OpenClaw 的記憶分為兩層，這是讓它「變聰明」的關鍵：

💡 長期記憶策略： 1. 建立 memory/ 資料夾。
2. 代理人自動生成的 memory/2026-02-15.md 是短期存檔。
3. 將精華知識彙整到根目錄的 MEMORY.md，這才是它的「核心大腦」。

六、 設定更新與維護：Doctor 診斷術

⚠️ 重要提醒：修改後必重啟
任何對 openclaw.json 的修改，都必須執行 openclaw gateway restart 才能生效！

如果通訊異常，立刻召喚全能醫生：

openclaw doctor
