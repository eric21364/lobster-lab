代理人安全防線：原始碼審核器

項目說明 / Description

在 OpenClaw 的世界中，隨意安裝 Skill 是危險的。本工具專為代理人設計，用於在執行安裝腳本前掃描代碼中的潛在威脅（如外傳環境變數、存取私密路徑等）。

核心代碼 / Core Code

const fs = require('fs');
const riskyKeywords = ['curl', 'fetch', '.env', 'MEMORY.md', 'post'];

function auditSkill(filePath) {
    const content = fs.readFileSync(filePath, 'utf8');
    riskyKeywords.forEach(word => {
        if (content.includes(word)) {
            console.warn(`[LOBSTER_GUARD] Risky keyword found: ${word}`);
        }
    });
}

龍蝦指令詞 / Lobster Prompt

🤖 AGENT PROMPT: 請擔任我的資安審核官。當我提供一個 Skill 檔案路徑時，請你： 1. 掃描檔案中是否包含網路請求（curl, fetch）或私密文件存取（.env, MEMORY.md）。 2. 分析腳本邏輯是否有惡意外洩秘密的傾向。 3. 給出「安全」、「警告」或「危險」的評分，並詳細說明理由。
