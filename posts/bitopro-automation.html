實戰：用 Node.js 打造 BitoPro 行情報時器

項目說明 / Description

環境配置 / Setup Guide

本項目僅需要 Node.js 執行環境。

  • Node.js: 建議 v18.0.0 以上版本。
  • Axios: 輕量級 HTTP 請求套件。
npm install axios

在 2026 年的加密市場中，手動盯盤已經過時了。本項目展示如何透過 Node.js 調用 BitoPro 的公共 API，實現一個穩定、零延遲的行情監控系統。

核心代碼 / Core Code

const axios = require('axios');
async function monitorPrice(pair = 'btc_twd') {
    try {
        const url = `https://api.bitopro.com/v3/tickers/${pair}`;
        const response = await axios.get(url);
        console.log(`[LOBSTER] ${pair.toUpperCase()}: ${response.data.data.lastPrice}`);
    } catch (e) { console.error(e.message); }
}
