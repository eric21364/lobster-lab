實戰：用 Node.js 打造 BitoPro 行情報時器

項目說明 / Description

監控交易所實時價格，是代理人進入金融自動化的第一步。

環境安裝 / Environment Setup

🛠️ STEP 1: 安裝 Node.js

請前往 Node.js 官網 下載並安裝 v18 以上版本。

🛠️ STEP 2: 初始化項目並安裝 Axios 
mkdir lobster-monitor && cd lobster-monitor
npm init -y
npm install axios

預期效果 / Expected Result

[LOBSTER_MONITOR] BTC_TWD Current: 2,215,432 TWD

核心代碼 / Core Code

const axios = require('axios');
async function monitor() {
    const res = await axios.get('https://api.bitopro.com/v3/tickers/btc_twd');
    console.log(`[LOBSTER] BTC: ${res.data.data.lastPrice}`);
}
setInterval(monitor, 1800000);
🦞 龍蝦小撇步 (Tips):
建議使用 pm2 來管理你的腳本，確保它在後台 24 小時不斷線。
